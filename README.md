# Memória em Libras — Frutas
WM Jogos Educativos

Jogo com 5 pares: foto da fruta e sinal em Libras. Dois jogadores, placar, editor e importação/exportação de cartas.

## Publicar no GitHub Pages
1. Extraia este ZIP no computador.
2. Crie um repositório no GitHub.
3. Em Add file > Upload files, envie os arquivos index.html, README.md e .nojekyll para a raiz do repositório e confirme em Commit changes. O arquivo index.html deve ficar diretamente na raiz, fora de subpastas.
4. Abra Settings > Pages.
5. Em Build and deployment, selecione Deploy from a branch.
6. Selecione a branch main e a pasta / (root). Clique em Save.
7. Aguarde a publicação. O endereço do jogo aparecerá nessa página.

Não é necessário instalar dependências ou executar build. As imagens estão incorporadas ao HTML. As edições das cartas ficam no navegador de cada dispositivo; use EXPORTAR CARTAS para transferi-las.

Fotos e sinais fornecidos pelo usuário. Marca: WM Jogos Educativos.
